# v2.1.0-beta.1 — Cave UI Plex documentation beta

Status: prepared candidate; public release and deployment held pending advance owner notice of the exact commit and artifacts.

The design documentation now uses the approved IBM Plex Sans and IBM Plex Sans Arabic typography, with real Regular, Medium, SemiBold and Bold weights. Canonical family tokens, downloadable Web templates and the actual Flutter gallery share the same identity. Existing semantic colours, components and Light/Dark/Black themes are retained.

The mobile header keeps the product name visible and exposes navigation, language, platform and appearance through a compact disclosure at 1024 px and below. Keyboard traversal, Escape, outside dismissal, focus restoration on resize, opaque scrollable panels and a usable no-script fallback are covered by browser tests.

The repository adds a regenerated bilingual README preview, contributor/release guidance, issue forms, a PR template, release-note configuration and verified website metadata.

Validation: 24 Node tests, TypeScript consumer checks, 133 Flutter tests and clean analysis; Web interactions and axe audits in Chromium/Firefox/WebKit; 72 responsive navigation cases plus Black short-screen and no-script checks; six independently extracted template ZIPs; actual compiled Flutter gallery in all three engines. See [validation](../VALIDATION.md) for boundaries and Brand compatibility results.

Package versions remain `0.1.0-alpha.1`. The website beta does not publish packages to npm or pub.dev. The website ZIP includes those evaluation downloads, bilingual site assets and compiled Flutter gallery. Verify the accompanying SHA-256 file against downloaded assets.

Human screen-reader sessions, physical-device testing, native Safari review of this candidate and a dedicated minimum-Flutter-SDK run remain outstanding. The Flutter Web compiler emits an SDK warning about an unused Cupertino icon family; no supported gallery scenario produced a missing font/resource request. Automated checks do not establish complete accessibility compliance.
