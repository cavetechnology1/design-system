# Changelog

- Align canonical typography, Web previews and actual Flutter examples with the approved IBM Plex Sans / IBM Plex Sans Arabic brand; retain real 400/500/600/700 weights and open-font notices.
- Add a compact bilingual documentation menu through 1024 px, keyboard and Escape handling, outside dismissal, focus restoration on resize, scrollable short-screen navigation and a no-script fallback.
- Refresh the README preview, contribution and release guidance, GitHub issue/PR templates and repository metadata.
- Keep package versions at 0.1.0-alpha.1 and registry publication paused. Website deployment and beta publication are held pending advance owner notice of the exact candidate.
